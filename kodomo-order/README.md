# こどもオーダー v2

ままごと・こども店長向けの簡易POS／モバイルオーダーです。本物の決済は行いません。

## できること
- タブレット／スマホから商品・数量を選んで注文
- 合計金額と注文番号を自動表示
- スタッフ画面で「注文受付 → 調理中 → できました → 提供済み」を更新
- 注文した端末の「注文のようす」に状態を反映
- 提供済み注文を当日の売上として集計
- 商品別販売点数・売上を集計
- 店名、商品名、絵文字、価格をアプリ内で編集
- ローカルで編集した店名・商品構成を、そのままクラウド化可能
- PWA対応（ホーム画面に追加してアプリ風に利用）
- ローカルモード：設定不要で1端末ですぐ試せる
- クラウドモード：Supabaseを使い、複数端末を同期

## ローカルで試す
このフォルダで以下を実行します。

```bash
python3 -m http.server 8000
```

`http://localhost:8000` を開きます。

## 複数端末同期の準備
1. Supabaseで無料プロジェクトを1つ作成。
2. SQL Editorで `supabase-schema.sql` の全文を実行。
3. Supabaseの Project URL と anon key を控える。
4. こどもオーダーの「設定 → クラウド接続を設定する」にURLとanon keyを入力。
5. 最初の端末で「この店をクラウド化」。表示された共有コードを控える。
6. 2台目以降に同じProject URL・anon keyを入力し、共有コードで参加。

クラウド時はSupabase Realtime Broadcastで更新通知を送り、5秒間隔の再取得も併用します。Broadcastが一時的に届かなくても自動で追いつく設計です。

## データの扱い
- 決済・クレジットカード情報は扱いません。
- 氏名などの個人情報を保存する設計ではありません。
- SupabaseのテーブルはRLSを有効化し、anonユーザーからの直接参照を無効化しています。
- アプリは十分長い共有コードをRPCに渡し、一致する店だけ読み書きします。
- プロトタイプ用途の設計です。一般公開サービスとして多数の利用者へ提供する場合は、認証・監査ログ・レート制限等を追加してください。
