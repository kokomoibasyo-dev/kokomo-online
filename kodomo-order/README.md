# こどもオーダー v3.2

ままごと・こども店長向けの簡易POS／モバイルオーダーです。**本物の決済は行いません。**

公開先（GitHub Pages）:
`https://kokomoibasyo-dev.github.io/kokomo-online/kodomo-order/`

## できること
- お客さん役・店員役のどちらからでも商品・数量を選んで注文
- 合計金額と注文番号を自動表示
- スタッフ画面で「注文受付 → 調理中 → できました → 提供済み」を更新
- 注文した端末の「注文のようす」に状態を反映
- 提供済み注文を当日の売上として自動集計
- 商品別販売点数・売上を集計
- 売上をCSVで書き出し
- 店名、商品名、絵文字、価格をアプリ内で編集
- 商品を「販売中／販売停止」に切替（売り切れ対応）
- PWA対応（ホーム画面に追加してアプリ風に利用）
- 全画面表示
- ローカルモード：設定不要で1端末ですぐ試せる
- クラウドモード：Supabaseを使い、複数端末を同期

## 端末別モード
通常URLはすべての画面を表示します。設定画面から、用途別の招待リンクをコピーできます。

- `?mode=order`：注文・注文状況（お客さん用）
- `?mode=staff`：注文入力・注文管理（店員用）
- `?mode=manager`：売上・設定（店長用）

クラウド接続後に「注文端末リンク」「スタッフ端末リンク」「店長端末リンク」をコピーすると、Supabase接続情報と共有コードをURLのフラグメントに含めます。別端末でそのリンクを開くと、その店に自動参加します。

> 招待URLは、その店へ参加するためのアクセスリンクです。SNSなど不特定多数には公開せず、使う端末・スタッフ間で共有してください。

## 複数端末同期の準備
1. Supabaseでプロジェクトを1つ作成。
2. SQL Editorで `supabase-schema.sql` の全文を実行。
3. Supabaseの Project URL と anon key を控える。
4. こどもオーダーの「設定 → クラウド接続を設定する」にURLとanon keyを入力。
5. 最初の端末で「この店をクラウド化」。
6. 設定画面の端末別リンクをコピーして、ほかのタブレットで開く。

手入力で参加する場合は、同じProject URL・anon keyと共有コードを入力して「共有コードで参加」でも接続できます。

クラウド時はSupabase Realtime Broadcastで更新通知を送り、5秒間隔の再取得も併用します。Broadcastが一時的に届かなくても自動で追いつく設計です。

## 売上の扱い
「提供済み」にした注文を売上として集計します。現金・模擬通貨などの実際の受け渡しはアプリ外で行います。

## データの扱い
- 決済・クレジットカード情報は扱いません。
- 氏名などの個人情報を保存する設計ではありません。
- SupabaseのテーブルはRLSを有効化し、anonユーザーからの直接参照を無効化しています。
- アプリは十分長い共有コードをRPCに渡し、一致する店だけ読み書きします。
- 招待URL内のSupabase anon keyは公開前提のクライアントキーですが、共有コードは店へのアクセス情報として扱ってください。
- 一般公開サービスとして多数の利用者へ提供する場合は、認証・監査ログ・レート制限等を追加してください。

## ローカルで試す
このフォルダで以下を実行します。

```bash
python3 -m http.server 8000
```

`http://localhost:8000` を開きます。


## 通知
- 注文状況／スタッフ画面の「通知をON」を一度押すと、音・振動通知を有効にできます。
- スタッフ端末：新しい注文が入ったときに通知します。
- お客さん端末：自分の注文が「できました」になったときに通知します。
- ブラウザの自動再生制限があるため、最初の1回だけ利用者のタップが必要です。

## 誤操作防止
「注文・売上をリセット」は、確認後に「リセット」と文字入力しないと実行されません。
